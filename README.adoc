== About

Notorious is a cross-platform notes desktop app: a catalog (list / grid / search), sticky-colored note windows, notepad editing with fonts/bold/size, and a **Text ↔ Canvas** mode switch. Canvas conversion turns paragraphs into canvas text blocks and stays reversible (with Undo) until diagram shapes are added.

Clipboard:

* *Ctrl+C* — HTML fragment **without** the sticky background color
* *Ctrl+Shift+C* — Markdown

Defaults favor code-friendly files: UTF-8 and LF line endings.

== Build

[source,bash]
----
# Co-dev: sibling checkouts of dlang-supplemental/dew and dui
dub build -c application --compiler=ldc2   # headless / SoftwareBackend smoke
dub build -c windowed --compiler=ldc2      # GLFW + Vello UI (Windows/Linux)
----

Windows installer: see `installer/notorious.iss` (Inno Setup). The Start Menu shortcut is named **Notorious** so Start search for “note” finds it.
